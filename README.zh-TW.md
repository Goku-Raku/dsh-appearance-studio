# Appearance Studio｜DSH 外觀工作室

[繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · [English](README.en.md) · [日本語](README.ja.md)

為官方 **DeepSeek Harness Desktop** 製作的非官方外觀插件：主題、壁紙、磨砂、圓角、氣泡與字體，並修整對話、軌跡和內建查看視窗的細節。

**適用對象：Windows 官方 Desktop 0.2.1-rc.2。** 獨立瀏覽器版、macOS、Linux 及其他版本尚未列為支援平台。套件中的 `platform: web` 表示 Desktop 內嵌的 Web Client API，並非瀏覽器版產品定位。

## 安裝與更新

1. 先確認官方 Desktop 版本為 **0.2.1-rc.2**。本版使用精確版本限制；其他版本請等待驗證，不建議強制跳過相容性檢查。
2. 從 [Releases](https://github.com/Goku-Raku/dsh-appearance-studio/releases/latest) 下載 `dsh-appearance-studio-1.0.0.tgz`；可用同頁 `SHA256SUMS.txt` 核對檔案。不要把 GitHub 的 Source code 壓縮包當作已打包插件。
3. 在 Desktop 的「插件 → 添加插件」中選擇套件／Bundle 安裝方式，輸入下載檔案的完整路徑；也可以把下面的請求交給 DSH Agent。這不需要另外啟動瀏覽器版 DSH。
4. 安裝完成並啟用後，在工作可中斷時重新整理 Desktop（Windows 通常為 Ctrl+R），再進入「設定 → 外觀工作室」。不要同時啟用舊的 `@local/dsh-appearance-studio` 開發副本。
5. 更新時先備份外觀設定，再從 Releases 安裝新版本。若宿主拒絕重複安裝，先停用並移除舊套件，再安裝新包；不要刪除外觀儲存資料。此專案目前透過 GitHub Release 分發，沒有宣稱已發布至 npm 或插件市場。

> 請用 plugin_manager 的 install_bundle 安裝我下載的 dsh-appearance-studio-1.0.0.tgz，target 填該檔案的完整本機路徑，安裝並啟用此 Bundle。

## 功能與累積改進

| 區域 | 功能／行為 |
| --- | --- |
| 主題與底紋 | 明亮、深色、跟隨系統；9 組底紋、11 套強調色及自訂色。Catppuccin Latte/Mocha、Nord Snow/Polar 映射、Rosé Pine Dawn/Main 可一鍵套用，保留字體、圓角、模糊等個別調整。 |
| 背景素材 | 7 組靜態漸層、無壁紙、自訂圖片。自訂圖片預載作者在「灼熱 Bonfire! MV」中製作的 AI 漫畫風 CHU² 圖；初始壁紙仍為「無」，點「自訂圖片」即可套用。可換圖、移除，原有儲存的圖片不被覆蓋。 |
| 外框／正文分層 | 頂部欄與左側欄使用較沉的外框材質，會話正文使用獨立閱讀底色。兩組底色濃度各 0–85%，兩組圖片模糊各 0–64 px；預設外框模糊 36 px、正文 0 px。漸層壁紙不顯示圖片模糊滑條。 |
| 羽化與新會話 | 會話上下保留固定 36 px 的模糊材質與羽化，與正文模糊滑條分開；歡迎頁及載入階段先隱藏上下效果，正式會話自動恢復。不透出其他系統視窗。 |
| 氣泡與強調色 | 明暗模式各自保存氣泡顏色；自訂色可切回且不遺失。深色氣泡顯示所選原色並調整文字對比。新會話／大型主按鈕採柔和填色，發送按鈕維持清楚的前景。 |
| 圓角 | 0–40 px 連續調整，0／16／40 快捷點。會話左下固定直角，側欄收起時左上也為直角；軌跡長條和內建查看視窗接縫有明確例外，不盲目套用圓角。 |
| 對話與輸入框 | 內容只顯示到輸入框上方，修補下緣小縫隙；對話／軌跡切換時輸入框保持同一位置與居中卡片形式，操作提示在輸入框上方顯示。 |
| 軌跡 | 顯示區與輸入區共用半透明底色，外緣貼邊；每條記錄固定直角，上方工具列與時間軸保留圓角。列表上下約 8 px 羽化只在還有內容可捲動時啟用，兩端靜止不遮字。 |
| 捲動與動效 | 提高淺色捲軸及會話側面索引的可見度；對話／軌跡標籤約 180 ms 滑動、內容約 160 ms 淡入，側欄約 260 ms 過渡，遵循減少動態效果偏好。 |
| 選單、預覽與 Dock | 大圓角選單只裁懸停裝飾，不裁文字／快捷鍵；檔案懸停預覽統一內外角與留白。內建查看視窗半開固定直角，全開左下直角；內部卡片及獨立浮動視窗不受影響。 |
| 程式碼與面板 | 行內程式碼保留 60% 底色且文字不變淡；整塊程式碼、檔案卡片保留各自表面。自動化面板圓角跟隨設定，側欄以留白和選中底色區分層次。 |
| 三類字體 | 介面、程式碼、終端分別選字體、字號與明暗文字色；可搜尋、分批捲動、手動輸入或刷新本機字體。透過宿主字體 API 保存；不取代語法高亮或 ANSI 顏色。 |
| 文字清晰度 | 次要／三級文字對比有預設、柔和、高對比；文字陰影有關閉、輕柔、清晰。陰影適用 CSS 文字，不覆蓋終端 Canvas 內容。 |
| 緊湊設定 | 主題及壁紙使用小色樣；圓角區減少垂直留白；文字對比與陰影左右排列。字體區左列字體／字號、右列預覽／顏色，色樣與色值合併，窄面板自動折行。 |
| 效能與清理 | 逐幀合併外觀更新，停止操作約 180 ms 後保存；圖片縮至長邊 1400 px、模糊結果最多 1100 px，每圖最多快取 4 檔模糊，捲動時不加 DOM 濾鏡。關閉壁紙及卸載時清理相關觀察器和樣式。 |

## 怎麼調整

- 想快速搭配：先選主題模式，再選一套開源主題；想細調再改強調色、底紋與壁紙。整套主題只改這三項。
- 使用自帶圖片：壁紙 → 自訂圖片。正文想清楚就把正文模糊設為 0；文字不易讀時先增加正文底色濃度，再調文字對比。外框與正文滑條各自獨立。
- 字體以本機實際安裝為準。內建 402 項名稱是開發機快照，不是附帶字型檔；其他電腦可能回退至系統字體。只有點「刷新系統字體」才請求權限，拒絕也可手動輸入。
- 自訂顏色按明暗模式分開；「預設顏色」只取消當前覆蓋，仍記得上次自選色。先切到要調整的模式再改顏色。
- 修改立即生效；頁面隱藏與正常卸載會保存待寫入設定，強制結束程序仍可能失去最後一小段連續操作。

## 資料、停用與回復

外觀與圖片保存在 Desktop 內嵌頁面的 `localStorage`（`dsh.appearance-studio.v2`，兼容 v1）；字體、字號與模式保存在宿主偏好。圖片以 Data URL 留在本機，建議輸入檔小於 2 MB，實際儲存配額依環境而異。插件本身不傳送網路請求、不執行 Shell、不需要 API Key；這不代表宿主或其他插件也離線。詳見 [安全與隱私](SECURITY.md)。

臨時停用：在 Desktop 插件管理停用，再於合適時重新整理。重新啟用可保留原設定。完全回復：先用外觀工作室底部「恢復預設」；需要手動清除時，只移除 v2／v1 外觀鍵，不要清空全部 localStorage。原生字體與模式請在宿主「外觀」設定另行恢復。卸載不應刪除聊天或工作區。

## 從原始碼打包

Node.js 20+，無執行期 npm 相依套件；React 由 Desktop 提供。`npm run check` 檢查發行檔、嵌入圖片與本機文件連結；`npm pack` 產生安裝包。套件不包含私有設定或內部交接文檔。

```sh
npm run check
npm pack --dry-run
npm pack
```
